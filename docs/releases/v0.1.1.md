本次更新修复邮件阅读、附件处理及账号同步体验。

- 保留邮件原有 HTML 排版、样式、表格和图片。
- 自动恢复旧版本丢失样式的正文缓存，打开邮件时重新获取原文；连接失败仍可查看缓存并重试。
- 修复原文下载完成后阅读区域仍显示旧内容的问题。
- 移除客户端自行设置的附件数量、大小及正文下载上限，由邮件服务商决定实际限制。
- 改进邮箱授权码的本地保存和更新，修复相关同步异常。
- 改进撰写、阅读和窄屏交互，精简设置提示。

下载时请选择对应平台的安装包。macOS 提供通用 DMG，Windows 提供 MSI 和 EXE，Android 提供 APK；AAB 用于分发。

macOS 包采用 ad-hoc 签名，未经过 Apple 公证；如首次打开被拦截，可在“系统设置 → 隐私与安全性”中允许。Windows 使用项目自签名证书，Android 使用项目固定签名。下载校验值见 SHA256SUMS.txt。
